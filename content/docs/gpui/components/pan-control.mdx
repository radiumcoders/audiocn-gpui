## Installation

```cargo
cargo add audiocn
```

## Usage

```rust
use audiocn::PanControl;
```

```rust
let view = cx.entity();

PanControl::new("pan")
    .value(self.pan)
    .on_value_change(move |pan, _window, cx| {
        view.update(cx, |this, cx| {
            this.pan = pan;
            cx.notify();
        });
    })
```

The value runs from −1 (left) to 1 (right). Dragging near the centre snaps to it, and double-clicking returns to it. `format_pan` turns a value into "L30", "C" or "R30", and `parse_pan` reads that text back.

For a rotary pan, use a [Knob](/docs/gpui/components/knob) with `.min(-1.)`, `.max(1.)`, `.origin(0.)`, `.format(format_pan)` and `.parse(parse_pan)`:

## Accessibility

The thumb is focusable and takes arrow keys (Shift for `large_step`), Page Up, Page Down, Home and End; the knob example supports the same keys. The thumb has the slider role and the name "Pan", and reads its value with `describe_pan`, such as "30% left" or "Center", while `format_pan` keeps the visible value short. The knob example uses the knob's own slider role.
