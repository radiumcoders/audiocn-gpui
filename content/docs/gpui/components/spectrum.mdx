## Installation

```bash
cargo add audiocn
```

## Usage

```rust
use audiocn::Spectrum;
```

```rust
use audiocn::io::{AnalyserTapOptions, MicrophoneOptions, use_microphone};

let mic = use_microphone(
    "mic",
    MicrophoneOptions {
        analyser: AnalyserTapOptions { bands: 64, ..Default::default() },
        ..Default::default()
    },
    window,
    cx,
);

Spectrum::new("spectrum").source(mic.visual.clone())
```

The spectrum draws the frequency bands of a visual frame. Set `min_hz`, `max_hz`, `min_db` and `max_db` to match the analyser that produced them, so the axes are labelled correctly. The defaults match `AnalyserTapOptions`. `Spectrum::new` takes an element id, which keeps the held peaks between renders.

The spectrum fills the width and is 160px tall by default, so size it with `Styled` methods such as `.h(..)` and `.max_w(..)`.

## Anatomy

```rust
use audiocn::{Spectrum, SpectrumCanvas, SpectrumFrequencyAxis, SpectrumLevelAxis};

Spectrum::new("spectrum")
    .child(SpectrumLevelAxis::new())
    .child(SpectrumCanvas::new())
    .child(SpectrumFrequencyAxis::new())
```

A spectrum with no children renders all three. `SpectrumLevelAxis` and `SpectrumFrequencyAxis` take `.ticks(..)` and `.format(..)`, and each `SpectrumCanvas` can override the spectrum's colours.

### Microphone

The browser preview has no microphone: "Use my microphone" feeds the spectrum from the demo speech signal instead, and stopping leaves the last frame drawn. In a native app, enable the `device` feature and pass the visual source of `audiocn::io::use_microphone`:

```bash
cargo add audiocn --features device
```

```rust
use audiocn::io::{AnalyserTapOptions, MicrophoneOptions, MicrophoneStatus, use_microphone};
use audiocn::Spectrum;

let mic = use_microphone(
    "mic",
    MicrophoneOptions {
        analyser: AnalyserTapOptions { bands: 64, fft_size: 4096, ..Default::default() },
        ..Default::default()
    },
    window,
    cx,
);
let listening = mic.status == MicrophoneStatus::Active;

Spectrum::new("mic-spectrum").peak_hold(true).source(mic.visual.clone())
// In a button's on_click: if listening { mic.stop(cx) } else { mic.start(cx) }
```

The gallery runs the real microphone with `cargo run -p audiocn-gallery --features device`.

## Theming

The spectrum paints with the active `audiocn::Theme`. The React CSS variables are builder options on `Spectrum` or on one `SpectrumCanvas`:

| React             | GPUI                 | Default             |
| ----------------- | -------------------- | ------------------- |
| `--spectrum`      | `.color(color)`      | `Theme::primary`    |
| `--spectrum-peak` | `.peak_color(color)` | `Theme::foreground` |
| `--spectrum-grid` | `.grid_color(color)` | `Theme::border`     |
