## Installation

```cargo
cargo add audiocn
```

## Usage

```rust
use audiocn::DbReadout;
```

```rust
DbReadout::new("peak").source(meter.clone())
```

`DbReadout::new` takes an element id, which keeps the readout's ticker between renders. With a `source`, the readout updates its own text four times a second from a GPUI task, and re-renders only when the text changes. Its width is reserved for the longest value, so the text never pushes neighbouring elements around.

## Examples

### Color by zone

React styles the readout with `data-zone` and `data-silent`. Here `.decorate(..)` hands you a `DbReadoutDisplay` with the current `zone` and `silent` flag, and the styled text element, so you can restyle or wrap it:

```rust
DbReadout::new("level")
    .source(meter.clone())
    .decorate(move |display, el| match display.zone {
        MeterZoneName::Clip => el.text_color(clip).into_any_element(),
        MeterZoneName::Warn => el.text_color(warn).into_any_element(),
        MeterZoneName::Ok => el.into_any_element(),
    })
```

## Theming

| React | GPUI |
| --- | --- |
| `data-zone` | `DbReadoutDisplay::zone`: `Ok`, `Warn` or `Clip` |
| `data-silent` | `DbReadoutDisplay::silent`: the level is at or below `floor_db` |

The readout is `Styled`, so text size, weight and colour are set with the usual GPUI style methods.
