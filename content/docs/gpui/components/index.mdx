## Meters and visualizers

| Component | What it is |
| --- | --- |
| [Level Meter](/docs/gpui/components/level-meter) | Peak and RMS meter with zones, peak hold, a scale, a readout and a clip light |
| [LCD Meter](/docs/gpui/components/lcd-meter) | A level meter in block segments on an LCD Display's screen |
| [dB Scale](/docs/gpui/components/db-scale) | Tick marks and labels for a decibel range |
| [dB Readout](/docs/gpui/components/db-readout) | A numeric level that updates at a readable rate |
| [Clip Indicator](/docs/gpui/components/clip-indicator) | A clip light that holds, counts and resets |
| [Bar Visualizer](/docs/gpui/components/bar-visualizer) | Bars driven by frequency bands |
| [Electric Bar Visualizer](/docs/gpui/components/electric-bar-visualizer) | Bars drawn as crackling filaments, with arcs and sparks |
| [Electric Waveform](/docs/gpui/components/electric-waveform) | One crackling electric line, as a smooth wave or an oscilloscope |
| [Smooth Waveform](/docs/gpui/components/smooth-waveform) | One clean line, as a smooth wave or an oscilloscope |
| [Live Waveform](/docs/gpui/components/live-waveform) | A canvas waveform of a live signal |
| [Waveform](/docs/gpui/components/waveform) | A clip's waveform with a playhead, seeking, regions and markers |
| [Spectrum](/docs/gpui/components/spectrum) | A frequency spectrum analyser |

## Controls

| Component | What it is |
| --- | --- |
| [Fader](/docs/gpui/components/fader) | A volume fader in decibels |
| [Parameter Slider](/docs/gpui/components/parameter-slider) | A labelled slider with a number input and a unit |
| [Tempo Control](/docs/gpui/components/tempo-control) | An editable BPM input with tap tempo |
| [Knob](/docs/gpui/components/knob) | A rotary control |
| [LCD Display](/docs/gpui/components/lcd-display) | A dot-matrix screen with glowing values and dropdown rows |
| [Pan Control](/docs/gpui/components/pan-control) | Left and right balance |
| [Channel Toggle](/docs/gpui/components/channel-toggle) | Mute, solo and monitor buttons |
| [Volume Control](/docs/gpui/components/volume-control) | A 0..1 volume slider with mute, for players |
| [Audio Device Select](/docs/gpui/components/audio-device-select) | A device picker with permission and disconnected states |
