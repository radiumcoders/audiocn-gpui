## Installation

```bash
cargo add audiocn
```

## Usage

```rust
use audiocn::{
    ParameterSlider, ParameterSliderControl, ParameterSliderHeader, ParameterSliderInput,
    ParameterSliderLabel,
};
```

```rust
let view = cx.entity();

ParameterSlider::new("sync-offset")
    .min(-1000.)
    .max(1000.)
    .step(5.)
    .unit("ms")
    .value(self.offset_ms)
    .on_value_change(move |ms, _window, cx| {
        view.update(cx, |this, cx| {
            this.offset_ms = ms;
            cx.notify();
        });
    })
    .child(
        ParameterSliderHeader::new()
            .child(ParameterSliderLabel::new("Sync offset"))
            .child(ParameterSliderInput::new()),
    )
    .child(ParameterSliderControl::new())
```

Use it for gain trims, delays, thresholds, times and frequencies. For volume, use [Fader](/docs/gpui/components/fader).

## Anatomy

```rust
ParameterSlider::new("parameter")
    .child(
        ParameterSliderHeader::new()
            .child(ParameterSliderLabel::new("Label"))
            .child(ParameterSliderReset::new())
            .child(ParameterSliderInput::new())
            .child(ParameterSliderValue::new()),
    )
    .child(ParameterSliderControl::new())
    .child(ParameterSliderMarks::new())
    .child(ParameterSliderDescription::new("Description"))
```

`ParameterSlider::new` takes an element id, which keeps the drag, focus and uncontrolled state between renders. The parts read the slider's state while they render, so they work in any layout inside it.

## Theming

The slider paints with the active `audiocn::Theme`, and every part implements `Styled`. The React data attributes have no GPUI equivalent:

| React | GPUI |
| --- | --- |
| `data-modified` | Compare the value with `reset_value`. `ParameterSliderReset` already hides itself when they match |
| `data-disabled` | `.disabled(true)` dims the slider |

## Accessibility

- `ParameterSliderLabel` names the slider thumb, or set `ParameterSliderControl::aria_label(..)`. The number input is exposed as a spin button with its value, but without the label's name.
- `ParameterSliderDescription` is visible help text. It is not attached to the thumb in GPUI.
- The thumb takes arrow keys (Shift for `large_step`), Page Up, Page Down, Home and End, like the [fader](/docs/gpui/components/fader#keyboard) without its Alt fine step. The number input takes Up and Down (Shift for `large_step`, Alt for 0.1) and typing; Enter or blur applies the text.
- Drag the unit next to the input to scrub the value.
