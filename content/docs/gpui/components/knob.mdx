## Installation

```cargo
cargo add audiocn
```

## Usage

```rust
use audiocn::{Knob, KnobDial, KnobLabel, KnobPointer, KnobRange, KnobTrack, KnobValue};
```

```rust
let view = cx.entity();

Knob::new("gain")
    .min(-24.)
    .max(24.)
    .origin(0.)
    .value(self.gain)
    .on_value_change(move |db, _details, _window, cx| {
        view.update(cx, |this, cx| {
            this.gain = db;
            cx.notify();
        });
    })
```

`Knob::new` takes an element id, which keeps the knob's drag and focus state between renders. Give each knob an id that is unique among its siblings. Leave out `.value(..)` and set `.default_value(..)` for an uncontrolled knob.

Drag the dial up to increase the value and down to decrease it. Set `.drag_direction(KnobDragDirection::Circular)` to turn it by circling around the dial, clockwise to increase and anticlockwise to decrease.

| Action | Result |
| --- | --- |
| Drag | Turns the knob |
| Shift+drag, Shift+wheel | Ten times finer, for precise adjustment. Press or release Shift mid-drag without a jump |
| Double-click the dial, Alt+click | Resets to `reset_value` |
| Double-click the value or label, Enter on the dial | Type a value; Enter applies it, Escape cancels |

The value keeps one width across the whole range, so the layout never moves while you turn it.

## Anatomy

```rust
Knob::new("gain")
    .child(
        KnobDial::new()
            .child(KnobTrack::new())
            .child(KnobRange::new())
            .child(KnobPointer::new()),
    )
    .child(KnobValue::new())
    .child(KnobLabel::new("Gain"))
```

A knob with no children gets this default anatomy. `KnobTrack`, `KnobRange` and `KnobPointer` are painted inside a 100 × 100 view box, in the order you add them. Paint your own shapes beside them with `KnobDial::paint`, which hands you a `KnobDialFrame` to map view box coordinates to pixels. `KnobScale` and `KnobCap` are another set of parts for the same dial, shown in the [volume dial](#volume-dial) and the [metal knobs](#metal-knobs).

## Examples

### Drag directions

Choose `.drag_direction(..)` to match how you want to move the dial:

- `KnobDragDirection::Vertical`, the default: drag up to increase the value, down to decrease it.
- `KnobDragDirection::Horizontal`: drag right to increase the value, left to decrease it.
- `KnobDragDirection::Circular`: turn clockwise to increase the value, anticlockwise to decrease it.

Hold Shift for finer control in all three modes. For vertical and horizontal drags, `.sensitivity(..)` sets the distance in pixels for the full range. The default is `200.`.

### Volume dial

A hi-fi volume dial: `KnobScale` draws numbered ticks around the dial and `KnobCap` a brushed aluminium cap with an indicator dot. Give it room for the numbers with a larger `.knob_size(..)`. `.click_sound(true)` adds a soft tick on each long graduation.

<GpuiExample demo="knob" variant="volume" />

Ticks between `origin` and the value light up, so a bipolar knob lights from its centre. The ticks are spread evenly along the arc, so they follow `.scale(KnobScaleType::Log)` too.

### Custom click sound

The knob decides when to click exactly like the React one, and hands each click to a `KnobClickPlayer` as a `ClickVoice`: a few milliseconds of synthesised samples at the player's rate. Play them with your audio engine. Set a player for the whole app with `cx.set_global(player)`, the way React uses `AudioContextProvider`, or for one knob with `.click_player(..)`. Without a player nothing plays, and nothing is synthesised.

```rust
cx.set_global(KnobClickPlayer::new(48_000, |voice, _cx| engine.play(voice.samples)));
```

Pass a `ClickSound` to `.click_sound(..)` to play a different click:

```rust
use audiocn::audio::click::{
    ClickNoiseChanges, ClickSoundChanges, ClickToneChanges, create_click_sound,
};

let thud = create_click_sound(ClickSoundChanges {
    tone: ClickToneChanges { hz: Some(460.), decay_ms: Some(1.3), gain: Some(1.) },
    noise: ClickNoiseChanges { decay_ms: Some(0.75), gain: Some(0.21) },
    volume: Some(0.18),
    ..Default::default()
});

Knob::new("thud").click_sound(thud)
```

A click is a decaying sine (`tone`) over a decaying noise snap (`noise`). Unset fields keep the default tick.

### Metal knobs

The same aluminium at everyday sizes: swap `KnobPointer` for `KnobCap::new().variant(KnobCapVariant::Mini)`. The mini cap fills the inside of `KnobTrack` and marks the value with an engraved line, which still reads at `AudioSize::Sm`.

## Theming

The knob paints with the active `audiocn::Theme`. The React CSS variables are builder options here:

| React | GPUI |
| --- | --- |
| `--knob-size` | `Knob::knob_size(px)`, or `.size(AudioSize)` |
| `--knob-cap-metal` | `KnobCap::metal(color)` |
| `--knob-cap-shade` | `KnobCap::shade(color)` |
| `--knob-cap-pitch` | `KnobCap::pitch(f32)` |
| `stroke-*` classes on the parts | `.color(..)` on `KnobTrack`, `KnobRange` and `KnobPointer` |
| `**:data-active:stroke-primary` on `KnobScale` | `KnobScale::active_color(color)` |

## Accessibility

The dial is focusable and takes the same keys as the [fader](/docs/gpui/components/fader#keyboard): arrows step by `step`, Shift+arrow, Page Up and Page Down by `large_step`, Alt+arrow by `fine_step`, Home and End jump to the ends, and Enter opens the value editor. The dial has the slider role, with its range and its value as `format` writes it. `KnobLabel` names it; without one, name it with `.aria_label(..)`.
