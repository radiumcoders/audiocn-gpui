## Installation

```cargo
cargo add audiocn
```

## Usage

```rust
use audiocn::ClipIndicator;
```

```rust
ClipIndicator::new("clip").source(meter.clone())
```

`ClipIndicator::new` takes an element id, which keeps the light, its count and its release timer between renders. The light turns on when any channel reaches −1 dBFS and stays on for 1.5 s. Clicking it resets the light and the count. Its size never changes, so turning on never moves the layout.

## Examples

### Latching, driven by hand

Set `.hold_ms(f64::INFINITY)` to keep the light on until someone resets it. Use `ClipIndicatorActions` to report levels from your own code.

<GpuiExample demo="clip-indicator" variant="latching" />

```rust
let clip = ClipIndicatorActions::new(); // keep it, e.g. in keyed state
ClipIndicator::new("clip").actions(clip.clone()).hold_ms(f64::INFINITY)
// later
clip.report(0., window, cx);
```

### Controlled

Pass `.clipping(..)` when another part of your app decides whether the signal clipped.

```rust
ClipIndicator::new("clip").clipping(engine.clipped)
```

`ClipIndicator` has no click handler of its own yet (React's `onClick`), so reset your engine's flag from your own control.

## Theming

The light paints with the active `audiocn::Theme`:

| React | GPUI |
| --- | --- |
| `--meter-clip` | `Theme::meter_clip`, the colour of the light when on. The count and text use `Theme::meter_clip_foreground` |
| `data-clipping` | `ClipIndicatorActions::clipping(cx)`, or `.on_clipping_change(..)` |

Children replace the default dot, so the light can be a word, an icon or anything else. Text children fade to the clip colour with the light. To restyle other children while clipping, read the state with `.on_clipping_change(..)` or `ClipIndicatorActions::clipping(cx)` and rebuild them.

## Accessibility

- A focusable element with the AccessKit role `Button`. Click, Enter or Space resets it. Its label changes to "Clipping. Reset clip indicator" while the light is on.
- GPUI has no live regions, so the React "Clipping" announcement has no equivalent.
