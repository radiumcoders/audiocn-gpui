## Installation

```cargo
cargo add audiocn
```

## Usage

```rust
use audiocn::VolumeControl;
```

```rust
let (on_volume, on_muted) = (cx.entity(), cx.entity());

VolumeControl::new("volume")
    .value(self.volume)
    .on_value_change(move |volume, _, cx| {
        on_volume.update(cx, |this, cx| {
            this.volume = volume;
            cx.notify();
        })
    })
    .muted(self.muted)
    .on_muted_change(move |muted, _, cx| {
        on_muted.update(cx, |this, cx| {
            this.muted = muted;
            cx.notify();
        })
    })
```

Unlike the mixer components, the volume here runs from 0 to 1, the same as `HTMLMediaElement.volume` in the React version. The `VolumeCurve::Perceptual` curve gives the slider more travel at low volumes, where ears are most sensitive. Unmuting at zero restores the last audible volume.

Leave out `.value(..)` and `.muted(..)` for an uncontrolled control, and set `.default_value(..)` and `.default_muted(..)` instead.

## Anatomy

```rust
VolumeControl::new("volume")
    .child(VolumeControlMute::new())
    .child(VolumeControlSlider::new())
    .child(VolumeControlValue::new())
```

A control with no children renders `VolumeControlMute` and `VolumeControlSlider`. The parts read the control's state while they render, so they must sit inside a `VolumeControl`.

## Theming

React sets `data-level` on the mute button so icons can switch with CSS. In GPUI, `VolumeControlMute::content` builds the button's children from a `VolumeControlMuteState`, whose `level` is `VolumeLevel::Muted`, `Low`, `Medium` or `High`, as in the first example:

```rust
VolumeControlMute::new().content(|state| {
    Icon::new(match state.level {
        VolumeLevel::Muted => IconName::SpeakerX,
        VolumeLevel::Low => IconName::SpeakerNone,
        VolumeLevel::Medium => IconName::SpeakerLow,
        VolumeLevel::High => IconName::SpeakerHigh,
    })
    .into_any_element()
})
```

Without children or `content`, the button shows the text "Mute" or "Unmute". Colours come from the active `audiocn::Theme`.
