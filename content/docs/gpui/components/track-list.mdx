## Installation

```bash
cargo add audiocn
```

## Usage

```rust
use audiocn::{
    TrackList, TrackListItem, TrackListItemContent, TrackListItemIndex, TrackListItemTitle,
};
```

```rust
let view = cx.entity();
TrackList::new("queue").children(tracks.iter().enumerate().map(|(index, track)| {
    let (view, id) = (view.clone(), track.id.clone());
    TrackListItem::new(track.id.clone())
        .active(track.id == current)
        .playing(track.id == current && playing)
        .on_select(move |_, cx| view.update(cx, |this, cx| this.play(&id, cx)))
        .child(TrackListItemIndex::new().child((index + 1).to_string()))
        .child(
            TrackListItemContent::new()
                .child(TrackListItemTitle::new().child(track.title.clone())),
        )
}))
```

`TrackList::new` and `TrackListItem::new` take element ids. A row keeps its focus under its id, so give each row an id that is unique in the list, like the track's id. `TrackListItemIndex` shows its children, or a small animated equaliser while the item is playing.

## Anatomy

```rust
TrackList::new("queue").child(
    TrackListItem::new("night-drive")
        .child(TrackListItemIndex::new())
        .child(TrackListItemArtwork::new(cover))
        .child(
            TrackListItemContent::new()
                .child(TrackListItemTitle::new())
                .child(TrackListItemDescription::new()),
        )
        .child(TrackListItemDuration::new())
        .child(TrackListItemActions::new()),
)
```

## Accessibility

- Up and Down move between items; Home and End jump; Enter or Space selects.
- The list and its rows have the list and list item roles. GPUI has no `aria-current`; the current row is shown by its background and a primary title.
- Buttons inside `TrackListItemActions` stay reachable with Tab and do not select the item.

Reordering is a recipe with GPUI's drag and drop (`on_drag` and `on_drop`), not built in.
