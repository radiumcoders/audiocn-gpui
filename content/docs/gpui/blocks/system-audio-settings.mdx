## Installation

```cargo
cargo add audiocn
```

The block is part of the crate: `audiocn::SystemAudioSettings`. To capture real system audio, add the `device` feature:

```cargo
cargo add audiocn --features device
```

## What it does

- A switch that starts and stops capture. In the browser that is the screen-share picker; natively, `audiocn::io::use_system_audio` captures the default output.
- A state label: Off, On, Choose what to share, No audio shared, Ended, Needs permission or Unsupported.
- A level control (−24 to +12 dB, default −6 dB) and a stereo meter while capture is on.
- Notices that explain what gets captured, or why nothing can be.

The block captures nothing itself. Pass the capture status and its meter, start and stop capture in `on_start` and `on_stop`, and apply the level from `on_gain_change` to the audio you route. There is no `MediaStream` in GPUI: `on_stream_change` reports `true` while the processed capture is live and `false` when it is not. Without a status and a meter, the switch drives a stereo demo signal, which is what the preview shows.

```rust
use audiocn::io::system_audio::is_supported;
use audiocn::io::{AnalyserChannels, AnalyserTapOptions, SystemAudioOptions, use_system_audio};
use audiocn::SystemAudioSettings;

let system = use_system_audio(
    "system",
    SystemAudioOptions {
        analyser: AnalyserTapOptions { channels: AnalyserChannels::Stereo, ..Default::default() },
        ..Default::default()
    },
    window,
    cx,
);
if let Some(stream) = system.stream() {
    stream.set_gain_db(self.gain_db);
}
let (start, stop) = (system.clone(), system.clone());
let view = cx.entity();

SystemAudioSettings::new("system")
    .supported(is_supported())
    .status(system.status().into())
    .meter_source(system.meter_source())
    .gain_db(self.gain_db)
    .on_gain_change(move |db, _, cx| view.update(cx, |this, cx| {
        this.gain_db = db;
        cx.notify();
    }))
    .on_start(move |_, _| start.start())
    .on_stop(move |_, _| stop.stop())
```

## Files

The block lives in `src/blocks/system_audio_settings.rs` of the `audiocn` crate. To change more than the builder options allow, copy the file into your app, rename the `crate::` paths to `audiocn::`, and edit it. One import is private to the crate: the `TextSize` helpers (`text_xs_()`, `text_sm_()`, ...), which set a font size and line height. Replace them with GPUI's `.text_size(px(12.)).line_height(px(16.))` and so on.
