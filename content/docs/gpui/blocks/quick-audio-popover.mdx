## Installation

```bash
cargo add audiocn
```

The block is part of the crate: `audiocn::QuickAudioPopover`. To control real microphones and system audio, add the `device` feature:

```bash
cargo add audiocn --features device
```

## What it does

The trigger shows the microphone state and a small live [bar visualizer](/docs/gpui/components/bar-visualizer). The popover holds the microphone select, on/off and mute buttons, and a system audio switch. Children go at the bottom, for a link to full settings.

The block opens no devices. Pass the device list and the analyser's visual source, and turn the microphone and system audio on and off in `on_microphone` and `on_system_audio`. Leave the microphone uncontrolled and pass no source, and "Turn on" feeds the bars with a speech demo signal, which is what the preview shows.

```rust
use audiocn::io::{MicrophoneOptions, MicrophoneStatus, use_audio_devices, use_microphone};
use audiocn::ui::{Button, ButtonSize, ButtonVariant};
use audiocn::{AudioDeviceKind, QuickAudioPopover};

let devices = use_audio_devices("audio/devices", AudioDeviceKind::AudioInput, window, cx);
let mic = use_microphone("audio/microphone", MicrophoneOptions::default(), window, cx);
let toggle = mic.clone();

QuickAudioPopover::new("quick-audio")
    .devices(devices.devices.clone())
    .microphone_active(mic.status == MicrophoneStatus::Active)
    .on_microphone(move |on, _, cx| if on { toggle.start(cx) } else { toggle.stop(cx) })
    .source(mic.visual.clone())
    .child(
        Button::new("audio-settings")
            .w_full()
            .size(ButtonSize::Sm)
            .variant(ButtonVariant::Ghost)
            .child("More audio settings"),
    )
```

## Files

The block lives in `src/blocks/quick_audio_popover.rs` of the `audiocn` crate. To change more than the builder options allow, copy the file into your app, rename the `crate::` paths to `audiocn::`, and edit it. It uses only the crate's public API.
