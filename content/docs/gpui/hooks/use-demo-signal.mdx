`use_demo_signal` makes meters and visualizers move without a microphone. Every GPUI example on this site runs on it. The signal is repeatable for a given `seed`, and it only runs while the view that calls it renders.

```bash
cargo add audiocn
```

## Usage

```rust
use audiocn::LevelMeter;
use audiocn::signal::demo_signal::{DemoSignalKind, DemoSignalOptions, use_demo_signal};

impl Render for Preview {
    fn render(&mut self, window: &mut Window, cx: &mut Context<Self>) -> impl IntoElement {
        let signal = use_demo_signal(
            "signal",
            DemoSignalOptions::kind(DemoSignalKind::Music).with_channels(2),
            window,
            cx,
        );
        LevelMeter::new("level").aria_label("Demo level").source(signal.meter)
    }
}
```

`use_demo_signal` keeps the signal in keyed state under its id, ticks it and requests the next animation frame. Call it from `render` with an id that is unique among its siblings.

Pass a fader's value with `.with_gain_db(..)` to meter the signal after gain. Set `.with_playing(false)` to mute it. Options apply on every render without resetting the pattern, so gain changes preserve the signal's timing and sources, and boosted readings can exceed 0 dBFS.

To change options, pass new ones on the next render. Outside a render, `DemoSignal::new(options)` gives the same sources with `meter_source()` and `visual_source()`; call `tick(now_ms())` once per frame and `configure(&options)` to change it.
