Meters paint every frame on their own. When you need the level in your view, for a label or to show a warning, `use_level` samples the source a few times a second and re-renders the view only when the level changes.

```bash
cargo add audiocn
```

## Usage

```rust
use audiocn::MeterZoneName;
use audiocn::signal::level::{LevelOptions, LevelState, use_level};

let LevelState { peak_db, zone, .. } =
    use_level("mic-level", Some(mic.meter.clone()), LevelOptions::default(), window, cx);

div().when(zone == MeterZoneName::Clip, |el| el.child("Turn your microphone down."))
```

Pass `None` as the source to stop sampling. Outside a render, `LevelSampler` holds the same state: call `poll(&source, now_ms)` and read `state()`.
