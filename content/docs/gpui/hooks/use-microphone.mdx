---
title: use_microphone
description: Open a microphone with its meter and visual sources built in, raw by default.
seoDescription: use_microphone opens a native microphone in GPUI with audiocn's device feature, with meter and visual frame sources for meters and visualizers, gain, mute and device choice.
---

```cargo
cargo add audiocn --features device
```

## Usage

```rust
use audiocn::io::{MicrophoneOptions, use_microphone};
use audiocn::ui::Button;

let microphone = use_microphone(
    "mic",
    MicrophoneOptions { device_id: self.device_id.clone(), ..Default::default() },
    window,
    cx,
);

div()
    .child(LevelMeter::new("mic-level").source(microphone.meter.clone()))
    .child(Button::new("start").child("Start").on_click(move |_, _, cx| microphone.start(cx)))
```

The microphone has an analyser built in, so `meter` and `visual` are ready for meters and visualizers, the job React's `useAudioAnalyser` does. They stay the same sources across start, stop and device changes.

Capture is always raw. Browsers can turn on echo cancellation, noise suppression and automatic gain control, and React keeps them off by default because they change the level a meter shows. Native capture has no such processing, so those options are accepted for parity and do nothing.

`UseMicrophone`, cheap to clone:

A `MicrophoneHandle` also has `set_gain_db` and `set_muted`, applied before analysis and routing. Outside a render, `Microphone::start(options)` opens a microphone and waits for it, and `Microphone::open(options)` returns at once.
