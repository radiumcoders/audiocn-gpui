`ClipHold` powers the [clip indicator](/docs/gpui/components/clip-indicator). Feed it every level reading; it tells you when the signal clipped and keeps that state for a while so people can see it.

```bash
cargo add audiocn
```

## Usage

React's `useClipHold` releases the light with a timer. `ClipHold` is plain state with no timer of its own: the release is a deadline on a millisecond clock, so it works the same in a view, a test or an audio thread.

```rust
use audiocn::audio::frame_loop::now_ms;
use audiocn::signal::clip_hold::{ClipHold, ClipHoldOptions};

struct Monitor {
    clip: ClipHold,
}

// in render:
let now = now_ms();
let peak_db = meter.with_latest(|frame| {
    frame.and_then(|frame| frame.channels.first()).map_or(f32::NEG_INFINITY, |c| c.peak_db)
});
self.clip.report(peak_db, now);
self.clip.update(now);
window.request_animation_frame();

div().when(self.clip.clipping(), |el| el.child(format!("Clipping ({})", self.clip.count())))
```

Create it with `ClipHold::new(ClipHoldOptions { hold_ms: 2000., ..Default::default() })`. `report` and `update` return `Some(clipping)` when the state changed, which is where React calls `onClippingChange`.
