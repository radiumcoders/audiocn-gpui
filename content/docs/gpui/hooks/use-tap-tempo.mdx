`TapTempo` powers the [tempo control](/docs/gpui/components/tempo-control). Use it with your own button, sound pad or key binding.

```cargo
cargo add audiocn
```

## Usage

```rust
use audiocn::audio::frame_loop::now_ms;
use audiocn::signal::tap_tempo::{TapTempo, TapTempoOptions};

let mut tempo = TapTempo::new(TapTempoOptions { default_value: 120., ..Default::default() });
```

Call `tempo.tap(now_ms())` once per beat. The second tap produces a BPM value; later taps average the last four intervals. A gap longer than two seconds starts a fresh sequence without changing the current value on its first tap. Taps less than 80 ms apart are ignored.

BPM values are always whole numbers. Tapped tempos, `value`, `default_value` and `set_value()` round to the nearest integer.

React calls `onValueChange` and `onValueCommitted` for you. Here `tap` returns a `TapOutcome` and `set_value` returns the new BPM, so you forward them yourself:

```rust
let outcome = self.tempo.tap(now_ms());
if let Some(bpm) = outcome.changed {
    self.bpm = bpm;
    cx.notify();
}
```

Call `tap()` from your app's key bindings or action handlers. Keep `TapTempo` in your view, and call `set_options` on every render when its options come from props.
