## Usage

React's `useWaveformData` fetches, decodes and reduces a file in one hook. In Rust the reduction is a plain function, and decoding is `AudioBuffer` behind the `device` feature. Run both on a background task:

```rust
use audiocn::io::AudioBuffer;
use audiocn::signal::waveform_data::{WaveformData, WaveformDataStatus, waveform_data_from_samples};

// When the view is created:
self.waveform = WaveformData::loading();
cx.spawn(async move |this, cx| {
    let data = cx
        .background_executor()
        .spawn(async {
            match AudioBuffer::load_cached("/audio/episode.mp3") {
                Ok(buffer) => waveform_data_from_samples(buffer.channels(), buffer.sample_rate() as f32, 800),
                Err(error) => WaveformData::error(error.to_string()),
            }
        })
        .await;
    this.update(cx, |this, cx| {
        this.waveform = data;
        cx.notify();
    })
})
.detach();

// In render:
Waveform::new("episode")
    .loading(self.waveform.status == WaveformDataStatus::Loading)
    .peaks_option(self.waveform.peaks.clone().map(Into::into))
    .duration(self.waveform.duration)
```

Peaks are the loudest sample in each slice, across all channels, normalised so the loudest slice is 1. `AudioBuffer::load_cached` decodes each file once; cache the peaks yourself if you compute them more than once.
